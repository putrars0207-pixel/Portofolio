# Rahmat Saputra — Portfolio Website

Website portofolio responsif berbasis HTML, CSS, dan JavaScript, dibuat berdasarkan CV Rahmat Saputra.

## Isi
- Profil profesional dan ringkasan pengalaman
- Pengalaman Staff Operasional RS Mohammad Hoesin, Pramubakti CSSD, dan Wedding Organizer
- Project Talent Coordinator TVRI, Tour Leader Pandawa 5 Tour, dan dasar project web/Android
- Keahlian, pendidikan, dan kontak
- Responsive mobile navigation dan tombol salin email

## Cara melihat secara lokal
Buka `index.html` di browser.

## Cara publish ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `rahmat-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md`.
3. Masuk ke **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses deploy selesai. GitHub akan menampilkan URL website pada halaman Pages.

## Personalisasi yang disarankan sebelum publikasi
- Ganti ilustrasi visual CSS di bagian pengalaman dan project dengan foto asli yang Anda miliki/berhak gunakan.
- Tambahkan foto profil profesional (jangan gunakan foto yang berisi data sensitif).
- Tambahkan tautan GitHub, LinkedIn, atau repositori project bila tersedia.
- Lengkapi nama perusahaan dan rentang waktu untuk pengalaman design editor/sales area jika ingin ditampilkan.
- Pastikan kontak yang dicantumkan memang ingin dipublikasikan.

## Catatan
Kartu visual pada versi awal adalah ilustrasi CSS, bukan dokumentasi foto asli. CV tidak memuat foto kerja atau screenshot project, sehingga gambar dokumentasi tidak dibuat-buat.
